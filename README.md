##  Project Overview

This repository houses a comprehensive summative data science lab focusing on complex machine learning domains. The project seamlessly integrates unstructured text processing, temporal statistical modeling, and deep neural network designs into a single reproducible pipeline.

### Key Competencies Demonstrated:
* **Advanced Text Preprocessing:** Tokenization, stopword removal, lemmatization, and text normalization.
* **Vectorization Pipelines:** Translating raw string tokens into numerical matrices using TF-IDF and word embeddings.
* **Sentiment Classification:** Building, training, and optimizing supervised models to categorize customer reviews accurately.
* **Time-Series Modeling:** Conducting stationarity checks, rolling statistics, and sequential forecasting.
* **Deep Neural Networks:** Constructing feedforward/recurrent network layers via TensorFlow and Keras.
* **Aesthetic Data Visualization:** Crafting custom dark-mode styled plots using Matplotlib and Seaborn.
